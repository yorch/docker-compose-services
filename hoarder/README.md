# Hoarder (Karakeep)

Bookmark manager with AI-powered tagging and full-text search.

## Features

- AI-powered automatic tagging
- Full-text search with Meilisearch
- Webpage screenshots via headless Chrome
- Browser extensions available
- Self-hosted and privacy-focused

## Quick Start

```bash
../setup-env.sh hoarder  # creates .env and generates NEXTAUTH_SECRET / MEILI_MASTER_KEY

# Dev - app on http://localhost:3000
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d

# Dev + Meilisearch admin UI (opt-in profile) on 127.0.0.1:3001
docker compose -f docker-compose.yml -f docker-compose.dev.yml --profile meilisearch-ui up -d

# Behind Traefik - HTTPS through the reverse proxy
docker compose -f docker-compose.yml -f docker-compose.for-traefik.yml up -d
```

The Traefik overlay joins an external network that must already exist. Create it
once per host:

```bash
../traefik3/setup.sh   # docker network create traefik
```

Behind Traefik set `NEXTAUTH_URL=https://${DOMAIN}`. Only the app is routed: Karakeep has
its own login, Meilisearch is reached only by the app, and the Meilisearch UI stays in the
dev overlay (see AGENTS.md). Set `DISABLE_SIGNUPS=true` once your accounts exist.

## Services

| Service          | Description                                                                  |
| ---------------- | ---------------------------------------------------------------------------- |
| `web`            | Karakeep web app and workers                                                 |
| `chrome`         | Karakeep's headless Chrome build, for crawling and screenshots               |
| `meilisearch`    | Full-text search (production mode, key required)                             |
| `meilisearch-ui` | Search admin UI, **dev overlay only**, opt-in via `--profile meilisearch-ui` |

## Environment Variables

| Variable           | Description                                                    | Required |
| ------------------ | -------------------------------------------------------------- | -------- |
| `NEXTAUTH_SECRET`  | Session signing secret (generated by `setup-env.sh`)           | Yes      |
| `MEILI_MASTER_KEY` | Meilisearch key, shared by the app and Meilisearch (generated) | Yes      |
| `NEXTAUTH_URL`     | Public URL (default `http://localhost:3000`)                   | Traefik  |
| `DOMAIN`           | Hostname Traefik routes to the app                             | Traefik  |
| `KARAKEEP_VERSION` | Image tag (default `0.33.2`)                                   | No       |
| `DISABLE_SIGNUPS`  | Disable new user registration (default `false`)                | No       |
| `DEV_BIND_IP`      | Host interface for dev Meilisearch / its UI                    | No       |
